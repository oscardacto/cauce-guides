# Glosario Retail / Ecommerce

| Término | Definición en este dominio |
|---|---|
| **SKU** | Stock Keeping Unit — identificador único de un producto en el inventario |
| **PDP** | Product Detail Page — página de detalle de producto |
| **PLP** | Product Listing Page — página de listado o catálogo |
| **Cart** | Carrito de compras — estado temporal antes del checkout |
| **Checkout** | Flujo de cierre de compra: dirección, pago, confirmación |
| **OMS** | Order Management System — gestión del ciclo de vida del pedido |
| **WMS** | Warehouse Management System — gestión de almacén e inventario |
| **Fulfillment** | Proceso de preparar y despachar un pedido |
| **Dropshipping** | El proveedor despacha directamente al cliente sin pasar por el almacén del comercio |
| **Marketplace** | Plataforma donde múltiples sellers venden a través de un canal único |
| **Seller** | Vendedor dentro de un marketplace |
| **Omnicanal** | Integración de canales físicos y digitales con experiencia unificada |
| **GMV** | Gross Merchandise Value — valor total de ventas brutas en la plataforma |
| **Conversion rate** | % de visitantes que completan una compra |
