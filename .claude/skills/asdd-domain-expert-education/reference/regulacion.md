# Regulación y Estándares — Educación / EdTech

## Normativa educativa

- Las plataformas que emiten certificaciones con valor oficial deben estar homologadas por el Ministerio de Educación
- Protección de datos de menores de edad: requiere consentimiento de los padres/tutores (COPPA en EE.UU., regulación local en LATAM)
- Accesibilidad: muchas instituciones educativas públicas están obligadas a cumplir WCAG 2.1 AA

## Estándares de contenido

- **SCORM 1.2 / 2004**: legacy — ampliamente soportado pero limitado a tracking básico (completado/puntuación)
- **xAPI**: moderno — permite registrar cualquier experiencia de aprendizaje, online u offline
- **IMS Global (LTI)**: Learning Tools Interoperability — integrar herramientas externas en el LMS

## Contenido adaptativo

El contenido adaptativo ajusta la experiencia según el perfil del estudiante:
- **Nivel**: diagnóstico inicial determina el punto de entrada
- **Ritmo**: el sistema detecta dónde el estudiante tiene dificultad y ofrece contenido de refuerzo
- **Estilo**: diferentes formatos (video, lectura, práctica) para distintos estilos de aprendizaje
