# Glosario Educación / EdTech

| Término | Definición en este dominio |
|---|---|
| **LMS** | Learning Management System — plataforma de gestión del aprendizaje |
| **LCMS** | Learning Content Management System — gestión y creación de contenido educativo |
| **Curso** | Unidad de aprendizaje estructurada con módulos, lecciones y evaluaciones |
| **Módulo** | Agrupación temática de lecciones dentro de un curso |
| **Lección** | Unidad mínima de contenido educativo (video, texto, actividad) |
| **SCORM** | Sharable Content Object Reference Model — estándar para contenido eLearning interoperable |
| **xAPI / Tin Can** | Estándar moderno de seguimiento de experiencias de aprendizaje (más flexible que SCORM) |
| **LRS** | Learning Record Store — repositorio de registros de aprendizaje xAPI |
| **Enrollment** | Inscripción de un estudiante a un curso |
| **Progress** | Progreso del estudiante en un curso (% completado) |
| **Completion** | Estado de haber completado todos los requisitos de un curso |
| **Certificación** | Acreditación formal de haber completado un programa con éxito |
| **Rúbrica** | Criterios explícitos para evaluar el desempeño en una actividad |
| **Gamificación** | Aplicación de mecánicas de juego (puntos, insignias, ranking) para motivar el aprendizaje |
