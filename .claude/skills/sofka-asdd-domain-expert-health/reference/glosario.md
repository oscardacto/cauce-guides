# Glosario Salud / Clínico

| Término | Definición en este dominio |
|---|---|
| **HCE / EMR** | Historia Clínica Electrónica / Electronic Medical Record — registro digital del historial del paciente |
| **EHR** | Electronic Health Record — registro de salud interoperable entre instituciones |
| **FHIR** | Fast Healthcare Interoperability Resources — estándar de interoperabilidad de datos clínicos (HL7) |
| **HL7** | Health Level 7 — organización y conjunto de estándares para intercambio de información clínica |
| **PHI** | Protected Health Information — información de salud protegida bajo HIPAA |
| **HIPAA** | Health Insurance Portability and Accountability Act — ley de privacidad de datos de salud (EE.UU.) |
| **ICD-10** | Clasificación Internacional de Enfermedades — codificación de diagnósticos |
| **SNOMED CT** | Nomenclatura sistematizada de medicina — terminología clínica estándar |
| **LOINC** | Logical Observation Identifiers Names and Codes — códigos para resultados de laboratorio |
| **Consentimiento informado** | Autorización explícita del paciente para tratamiento y uso de sus datos |
| **Interoperabilidad** | Capacidad de sistemas distintos de intercambiar y usar información clínica |
| **Prescripción electrónica** | Orden médica digital para medicamentos, enviada directamente a la farmacia |
