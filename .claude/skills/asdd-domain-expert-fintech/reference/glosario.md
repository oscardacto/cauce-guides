# Glosario Fintech / Banca

| Término | Definición en este dominio |
|---|---|
| **PAN** | Primary Account Number — número de tarjeta de 16 dígitos. Nunca almacenar en claro |
| **CVV** | Card Verification Value — código de seguridad. Nunca almacenar, ni cifrado |
| **Token** | Representación sustituta del PAN, generada por el TSP. Sin valor fuera del sistema |
| **TSP** | Token Service Provider — entidad que gestiona la tokenización (Visa, Mastercard) |
| **Acquirer** | Banco que procesa transacciones en nombre del comercio |
| **Issuer** | Banco emisor de la tarjeta del cliente |
| **Switch** | Red de enrutamiento de transacciones (Visa Net, Mastercard Network) |
| **KYC** | Know Your Customer — proceso de verificación de identidad del cliente |
| **AML** | Anti-Money Laundering — prevención de lavado de activos |
| **Conciliación** | Proceso de verificar que los registros internos coincidan con los del banco |
| **Core bancario** | Sistema central que gestiona cuentas, saldos, transacciones y productos |
| **Chargeback** | Reversión de cargo iniciada por el cliente ante el banco emisor |
| **Clearing** | Proceso de intercambio de información entre bancos para liquidar transacciones |
| **Settlement** | Liquidación final — transferencia real de fondos entre instituciones |
