# Glosario Seguros

| Término | Definición en este dominio |
|---|---|
| **Póliza** | Contrato entre asegurador y asegurado que establece cobertura, prima y condiciones |
| **Prima** | Precio que paga el asegurado por la cobertura. Puede ser única, mensual o anual |
| **Siniestro** | Ocurrencia del evento cubierto por la póliza que genera una reclamación |
| **Cobertura** | Riesgos específicos que ampara la póliza y sus límites |
| **Deducible** | Monto que asume el asegurado antes de que la póliza cubra el resto |
| **Endoso** | Modificación a una póliza emitida (añadir cobertura, cambiar datos, etc.) |
| **Vigencia** | Período de tiempo durante el cual la póliza está activa |
| **Reaseguro** | Contrato por el cual una aseguradora transfiere parte de su riesgo a otra |
| **Cedente** | Aseguradora que transfiere riesgo al reasegurador |
| **Actuaría** | Disciplina que calcula probabilidades de riesgo y tarifas de primas |
| **Reserva técnica** | Provisión contable que la aseguradora debe mantener para cubrir siniestros futuros |
| **PML** | Probable Maximum Loss — pérdida máxima probable en un evento catastrófico |
| **Cotizador** | Herramienta que calcula la prima según los datos de riesgo del asegurado |
