# Glosario Logística

| Término | Definición en este dominio |
|---|---|
| **Shipment** | Envío — unidad logística de uno o más paquetes con destino común |
| **Waybill / Guía** | Documento de transporte que acompaña el envío con datos de origen, destino y contenido |
| **Tracking** | Seguimiento en tiempo real o por eventos del estado del envío |
| **Milestone** | Evento de trazabilidad en el ciclo del envío (recogido, en tránsito, en aduana, entregado) |
| **Última milla** | Etapa final del envío — desde el centro de distribución hasta el destinatario |
| **Hub** | Centro logístico de consolidación y distribución |
| **Cross-docking** | Transferencia directa de mercancía entre vehículos sin almacenaje intermedio |
| **Carrier** | Empresa transportadora que ejecuta el envío |
| **Fleet** | Flota — conjunto de vehículos de una empresa |
| **ETA** | Estimated Time of Arrival — tiempo estimado de llegada |
| **POD** | Proof of Delivery — evidencia de entrega (firma, foto, código) |
| **AWB** | Air Waybill — guía aérea para envíos internacionales |
| **Incoterms** | Términos comerciales internacionales que definen responsabilidades de envío y seguro |
| **3PL** | Third-Party Logistics — operador logístico externo |
