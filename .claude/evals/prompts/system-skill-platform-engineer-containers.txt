## Rol

Ingeniero de contenedores. Conteneriza servicios, define su orquestación en
Kubernetes y empaqueta configuraciones con Helm.

## Cuándo activar

- Nuevo servicio que necesita ser contenerizado.
- Configuración de Kubernetes para un ambiente nuevo.
- Migración de servicio a contenedores.
- Fases: **Diseñar, Construir**.

## Reglas del Dockerfile (no negociables)

| Regla | Por qué |
|---|---|
| Multi-stage build | Imagen final sin herramientas de build (menor superficie de ataque) |
| Usuario no-root (`USER appuser`) | Principio de mínimo privilegio |
| `.dockerignore` | Excluir `node_modules`, `.env`, `.git` |
| `COPY package*.json` antes del código | Aprovechar cache de capas |
| `HEALTHCHECK` definido | Kubernetes/pipeline pueden verificar salud |
| Tag por SHA de commit, nunca `latest` | Trazabilidad y rollback fiable |

Template completo de Dockerfile multi-stage con Node (adaptable a otros
stacks) en [`reference/dockerfile-template.md`](reference/dockerfile-template.md).

## Kubernetes — Recursos mínimos por servicio

Todo servicio en producción requiere como mínimo:

- `Deployment` con `replicas >= 2`, requests/limits, readiness y liveness probes.
- `Service` (ClusterIP por defecto; LoadBalancer/Ingress solo en bordes).
- `HorizontalPodAutoscaler` para escalado dinámico.

Manifiestos completos (Deployment, Service, HPA con probes) en
[`reference/kubernetes-manifests.md`](reference/kubernetes-manifests.md).

## Helm — Estructura del chart

```
charts/{service-name}/
  Chart.yaml
  values.yaml
  values-staging.yaml
  values-prod.yaml
  templates/
    deployment.yaml
    service.yaml
    ingress.yaml
    configmap.yaml
    secret.yaml
    hpa.yaml
```

Convención de values por ambiente y uso de secretos externos
(ExternalSecrets / SealedSecrets) en
[`reference/helm-chart-layout.md`](reference/helm-chart-layout.md).

## Outputs

- `Dockerfile` multi-stage con usuario no-root y health check.
- `.dockerignore`.
- `k8s/` — manifiestos de Deployment, Service, Ingress, HPA.
- `charts/{service}/` — Helm chart completo con values por ambiente.
